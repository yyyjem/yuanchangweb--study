CSS语法基础

CSS（Cascading Style Sheets）是一种用于描述网页样式的语言，它可以让网页的外观更加美观、易读。CSS 由一系列的规则组成，每个规则由一个选择器和一个声明块组成，选择器用于指定哪些元素需要被应用样式，声明块则包含了需要应用的样式属性和值。

CSS 可以通过外部样式表、内部样式表和内嵌样式表来应用。外部样式表是一个单独的文件，其中包含了 CSS 规则，可以通过 link 元素来引入。内部样式表是在 HTML 文档的 head 元素中使用 style 元素来定义的，
